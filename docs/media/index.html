歴史解説で特定の国や民族を攻撃することはありますか？

一切ありません。対立を煽るのではなく、公文書館・国際機関・歴史研究で確認できる一次史料と複数地域の記述を中立的に並べることで、誤解を解くことを目的としています。

宗教団体やスピリチュアル勧誘とは関係がありますか？

一切無関係です。本サイトおよびコミュニティは、検証可能な一次データ・歴史史料・実務ツールを扱う純粋な教育・メディア研究室です。高額献金や不安を煽る勧誘は永久に禁止しています。

子どもや学生の自由研究・調べ学習に引用してもよいですか？

はい、大歓迎です。各章に記載している一次史料名（国立公文書館・国連文書・歴史書等）をご自身でも直接確認しながらご活用ください。
